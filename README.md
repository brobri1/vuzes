# 1. Сначала: что такое DAPL/04 и DAPL/06

В системе AFAM:

**DAPL/04** — Diploma Accademico di Primo Livello in **Grafica** / **Grafica d’Arte**.
**DAPL/06** — Diploma Accademico di Primo Livello in **Progettazione Artistica per l’Impresa**; внутри этого класса академия может открывать разные профили: Graphic Design, Product Design, Fashion Design, Jewelry Design, Illustration/Fumetto и т. д. Это хорошо видно, например, по Bologna, Ravenna и Cuneo. ([valutazioni-afam.mur.gov.it][2])

То есть очень важно не путать **код программы** с названием конкретного трека. Например, в Bologna и Firenze код DAPL06 относится сразу к нескольким направлениям. ([assets.ababo.it][3])

## DAPL/04 — Grafica d’Arte, Torino

Для 2026/27 официальный экзамен Albertina очень конкретный. 

### Экзамен

**Первая часть — практическая, максимум 6 часов.**

Кандидат делает **две работы**:

1. **копия с натуры**;
2. **reinterpretazione** — авторская интерпретация.

Для копии:

* натюрморт;
* преимущественно гипсовые слепки античных скульптур и другие предметы;
* чёрно-белое решение;
* обязательный chiaroscuro;
* бумага академии **50×70 см**;
* инструменты кандидат приносит сам.

Для reinterpretazione можно использовать цвет; академия рекомендует иметь при себе различные материалы: тушь, акварель, нож, клей, газеты и т. п. 

### Вторая часть — colloquio

Вопросы касаются:

* истории искусства **XIV–XXI веков**;
* современного искусства;
* мотивации;
* интересов;
* целей кандидата.

И очень важно: на собеседовании надо представить **portfolio, цифровое или бумажное**. 

### Как должно выглядеть портфолио для DAPL/04 Torino

Официальный документ не задаёт жёсткое количество страниц или конкретный шаблон. Поэтому оптимальная структура — это **не “альбом всех работ”, а отобранная профессиональная выборка**.

Приоритет я бы выставлял так:

**1. рисунок и наблюдение**
натура, предметы, анатомические зарисовки, sketchbook;

**2. графика и печатные техники**
linocut, xilografia, calcografia, serigrafia, litografia;

**3. иллюстрация / visual storytelling**;

**4. авторские проекты**;

**5. graphic design / digital work** — как дополнение, а не вместо художественной графики.

Это соответствует тому, что сама академия описывает как профильные для Grafica d’Arte материалы: рисунки, sketchbook, печатные работы, calcografia, xilografia, serigrafia, litografia и т. п. 

**Хорошая стратегия:** около 12–20 сильных проектов/серий, а не 50 случайных работ.

# 4. DAPL/06 — Progettazione Artistica per l’Impresa, Torino

Здесь ситуация совсем другая.

## Экзамен 2026/27

У Albertina для Triennio P.A.I. был отдельный официальный экзамен **17 сентября 2026**, продолжительность **3 часа**. ([albertina-academy.it][7])

Экзамен состоит из двух частей.

### A. Практическое проектное задание — 120 минут

Комиссия даёт **4 brief**, кандидат выбирает один:

* Product;
* Fashion;
* Grafica / Comunicazione visiva;
* Web / Digitale.

Работа выполняется **традиционными средствами**, а не в Photoshop/Illustrator/Figma.

Можно использовать:

* рисунок от руки;
* технический рисунок;
* sketch;
* композиционные схемы;
* collage;
* figurini;
* conceptual representation.

Оцениваются:

* проектное мышление и оригинальность — 20;
* соответствие brief — 15;
* ясность визуального результата — 10;
* способность синтезировать идею — 10;
* организация и полнота — 5. ([albertina-academy.it][7])

### B. Теоретический тест — 45 минут

* 20 multiple choice;
* 1 короткий открытый вопрос.

Темы включают:

* современную визуальную культуру;
* историю искусства и дизайна;
* graphic/visual communication;
* цвет, знак, типографику;
* композицию;
* форму и функцию;
* product culture;
* sustainability;
* основы technical drawing;
* perspective / axonometry;
* interface и layout;
* digital formats. ([albertina-academy.it][7])

**Важно:** Albertina прямо пишет, что специальная продвинутая подготовка в конкретном software не требуется. Основной объект оценки — **образ мышления, наблюдение, интерпретация, креативность и проектная способность**. ([albertina-academy.it][7])

---

## Портфолио для DAPL/06 Torino

Для **Triennio** Albertina в опубликованной инструкции делает основной упор на самом вступительном экзамене; отдельного обязательного PDF-портфолио для обычного очного кандидата в этом документе не установлено.

Зато для **Biennio** DAPL06 академия уже прямо требует portfolio и очень подробно его описывает: PDF, личные данные, образование, опыт, визуальная документация, проекты по выбранному направлению, описание каждого проекта, ссылки на видео/web и declaration of authenticity. ([albertina-academy.it][8])

Практически это означает:

### Для поступающего на Triennio DAPL06 я бы готовил portfolio таким:

**Design / Graphic Design / Fashion / Product**, в зависимости от вашего трека:

* 3–5 сильных законченных проектов;
* sketch development;
* moodboard / research;
* problem statement;
* early concepts;
* iterations;
* final;
* фотографии physical prototype, если он есть;
* technical drawings;
* typography / identity для graphic track;
* material studies для product;
* fabric / silhouette / collection development для fashion.

То есть комиссии лучше показать **процесс проектирования**, а не только красивые финальные картинки.

## DAPL06 — Design Grafico

Это один из самых интересных вариантов, если вы хотите именно graphic/communication design.

В бандо 2026/27 экзамен состоит из нескольких элементов. 

### 1. Motivational/aptitude interview

Нужно представить **portfolio в бумажном и цифровом формате**.

В портфолио:

* graphic design;
* можно включать photography;
* illustration;
* art;
* другие работы, показывающие креативность и visual/conceptual thinking.

### 2. Теоретическая часть

Во время собеседования обсуждается один из выбранных кандидатом материалов AIAP Journal, в актуальном бандо перечислены, среди прочего:

* *Creatività e cultura nell’epoca dell’AI generativa*;
* *Mapping Inequalities*;
* *Monogrammi e figure*. 

### 3. Практическая задача

Нужно разработать **Guerrilla Advertising campaign** на тему Международного дня борьбы с насилием против женщин — **25 ноября 2026**.

Нужно представить:

* концепцию кампании;
* **manifesto**;
* итоговый напечатанный материал;
* сокращённую версию manifesto в формате **A3**. 

Причём академия специально пишет, что предпочитает решения:

* не риторические;
* не банальные;
* не чрезмерно прямолинейные;
* показывающие самостоятельную идею автора.

### Когда

**Design Grafico — 15 сентября 2026.** ([Ababo][10])

### Что я бы положил в portfolio

Для этого направления:

* 2–3 branding проекта;
* 2 poster/editorial проекта;
* 1 identity system;
* 1 social campaign;
* 1 digital/UI project;
* typography;
* sketchbook/research;
* 1–2 экспериментальных проекта.

И очень желательно, чтобы хотя бы один проект был **развёрнут как case study**:

> проблема → исследование → концепция → варианты → отбор → система → финальный результат.

## DAPL06 — Design del Prodotto, Bologna

Экзамен совсем другой:

* **project challenge** на основании темы от преподавателей;
* свободная техника;
* можно использовать drawing, ruler/square, collage, pastel и т. д.;
* рекомендуется взять ножницы, клей, cutter, tape;
* затем индивидуальное собеседование примерно на **10 минут**;
* portfolio **не является обязательным**, но его можно загрузить в Spaggiari. 

Значит, для Product Design комиссия в первую очередь смотрит, **как вы решаете задачу**, а не насколько “красивый PDF” вы подготовили.

# 15. Что должно быть в сильном portfolio для AFAM в целом

Не существует одного единого “итальянского стандарта портфолио”: требования задаёт конкретная академия и конкретный курс. Но по официальным требованиям выше хорошо просматривается общий принцип.

Я бы строил PDF примерно так:

**1. Cover**
Имя + выбранный курс + contact.

**2. Short profile**
5–8 строк: образование, направление интереса, что хотите изучать.

**3. Sketchbook / Research**
10–15 страниц.

**4. Project 1**
problem → research → sketches → alternatives → final.

**5. Project 2**
другая техника/другая задача.

**6. Project 3**
самый сильный самостоятельный проект.

**7. Technical / process section**
drawings, construction, materials, prototypes.

**8. Experimental section**
личные визуальные исследования.

**9. Optional digital work**
animation, motion, UI, web, 3D и т. п.

**10. Final selection**
5–10 наиболее сильных изображений без лишнего текста.

Для **DAPL04** увеличиваем долю drawing / engraving / illustration / print.
Для **DAPL06 Graphic Design** — identity / typography / editorial / campaign / digital.
Для **DAPL06 Product** — sketching / technical drawing / prototype / materials.
Для **DAPL06 Fashion** — collection / silhouettes / textile / research / technical flats.
Для **DAPL06 Jewelry** — form / materials / technical drawings / objects / prototype / 3D.

# 16. Практический маршрут поступления

Для вас оптимальная стратегия сейчас выглядит так:

**Шаг 1.** Определить не просто DAPL-код, а конкретный профиль.
Например: **DAPL06 Graphic Design**, а не просто DAPL06.

**Шаг 2.** Выбрать 2–4 академии.

**Шаг 3.** Сделать один базовый portfolio, затем адаптировать его под каждую комиссию.

**Шаг 4.** Отдельно готовиться к экзамену каждой школы. Это особенно критично для Torino, где экзамены DAPL04 и DAPL06 совсем разные. 

**Шаг 5.** Для Firenze обязательно проверять именно новый admission notice соответствующего учебного года, а не автоматически использовать старый PDF с практическими экзаменами. ([Академия изящных искусств Флоренции][16])
